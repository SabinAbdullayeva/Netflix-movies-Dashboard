# Netflix-movies-Dashboard
Netflix-in film və serial məlumatlarını təhlil etmək və vizuallaşdırmaq üçün GitHub üzrə yaradılmış dashboard
Power BI və Kaggle məlumatları əsasında hazırlanan Netflix Filmləri və Serialları İdarəetmə Paneli (Netflix Movies and TV Shows Dashboard) üçün Azərbaycan dilində peşəkar və səliqəli README.md faylı.

Bu layihə Netflix platformasındakı film və serialların hərtərəfli təhlili üçün Power BI istifadə olunaraq hazırlanıb. İdarəetmə paneli (dashboard) məzmun bölgüsü, illər üzrə artım dinamikası və janr populyarlığını interaktiv şəkildə nümayiş etdirir.
🎯 Layihənin Məqsədi
Netflix kataloqundakı film və serialların ümumi balansını müəyyən etmək.
Ölkələr və illər üzrə istehsal trendlərini analiz etmək.
Yaş kateqoriyaları (ratings) və janrlar üzrə izləyici meyillərini qiymətləndirmək.
🛠️ İstifadə Olunan Alətlər və Texnologiyalar
Power BI Desktop: İnteraktiv qrafiklərin və vizualların qurulması.
Power Query / Excel: İlkin məlumatların təmizlənməsi və transformasiyası.
Dataset: Kaggle üzərindən əldə edilən netflix_titles.csv məlumat bazası.
📈 Əsas Göstəricilər və Vizuallar (KPIs)
Ümumi Məzmun Sayı: Film və serialların yekun miqdarı.
Film vs Serial (Movie vs TV Show) Bölgüsü: Kateqoriyalar üzrə faiz nisbəti.
Xəritə Vizualı: Ölkələr üzrə istehsal olunan məzmunların qlobal xəritədə göstəricisi.
Zaman Qrafiki (Time Series): 2008–2021-ci illər aralığında platformaya əlavə olunan başlıqların artım dinamikası.
Top 10 Janr: Ən çox üstünlük verilən kateqoriya və janrların reytinq
🚀 Quraşdırma və İstifadə
Bu repozitoriyanı klonlayın və ya ZIP olaraq yükləyin.Netflix Dashboard.pbix faylını Power BI Desktop proqramında açın.Əgər məlumatlar yenilənməzsə, mənbə fayl yolunu (netflix_titles.csv) öz yerli qovluğunuzla əvəzləyin.
